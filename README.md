# AURA | Artisan Burgers

A sophisticated, single-page fine-dining restaurant application built for **The Odin Project**. 

This project showcases modern JavaScript modular architecture, DOM manipulation, responsive design, and asset bundling via Webpack.

## Features

* **Modular ES6 Architecture:** Clean separation of concerns with independent modules for the Home, Menu, and About views.
* **Dynamic DOM Manipulation:** Seamless view-switching via interactive navigation buttons without page reloads.
* **Webpack Asset Bundling:** Configured with Webpack, HTMLWebpackPlugin, and style/css loaders for optimized production builds.
* **Fully Responsive Design:** Tailored layouts that adapt fluidly from wide desktop monitors down to mobile phone screens.
* **Luxury Branding:** Custom dark-obsidian aesthetic with gold accents and high-end culinary copywriting.

## Built With

* JavaScript (ES6+ Modules)
* Webpack 5
* HTML5 & CSS3 (Flexbox, Media Queries)
* Git & GitHub
* Node.js & npm
